## Kinn
Sensing kinesiology tape with a reusable snap-in coin for tracking physical therapy recovery.

- **Start here:** [`kinn/CONTEXT.md`](kinn/CONTEXT.md) covers the product, decisions, market notes and next steps.
- **App spec:** [`kinn/docs/feature-spec.md`](kinn/docs/feature-spec.md), [`kinn/docs/architecture.md`](kinn/docs/architecture.md), [`kinn/docs/decisions.md`](kinn/docs/decisions.md)
- **AI demo (hackathon, Continual Learning):** [`kinn/learn/`](kinn/learn/) is the interactive page showing how Kinn learns from each wearer and from everyone. Vite + React, built into the site and served at `/learn`.
- **Website + waitlist:** [`kinn/site/`](kinn/site/) is the static page plus a small Express API, deployed on Vercel with signups saved to Postgres (Neon). Setup is in its README.
- **Renders and video:** [`kinn/renders/`](kinn/renders/), [`kinn/video/`](kinn/video/)
- **Blender scene scripts:** [`kinn/blender/`](kinn/blender/)
